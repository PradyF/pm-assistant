# 🤖 AI PM Assistant

Интеллектуальный ассистент для управления проектами в **Kaiten**. Объединяет дашборд метрик, AI-советника и командный чат — всё работает в реальном времени через API.

**🔗 Живое демо:** [https://assistant.ya-zelinsky.ru](https://assistant.ya-zelinsky.ru)

---

## ✨ Что умеет

### 📊 Дашборд метрик
- **Ключевые метрики:** всего задач, просрочено, WIP, закрыто за 7 дней
- **Flow-метрики:** Velocity, застрявшие задачи, Predictability, прогноз релиза
- **Диаграмма сгорания** (Burndown) с идеальной, реальной линией и прогнозом
- **График по колонкам** с сортировкой
- **Нагрузка команды** — прогресс-бары по каждому исполнителю
- **Просроченные задачи** — список с дедлайнами

### ✨ AI-советник
Анализирует метрики проекта и даёт конкретные рекомендации:
- Указывает на главные риски («3 просрочки блокируют релиз»)
- Предлагает действия («перераспределить 2 задачи с Маши на Ивана»)
- Прогнозирует сценарии («при текущем темпе релиз 13.10»)

**Кэширование:** одинаковые метрики → ответ из кэша, без траты токенов.

### 💬 Команды на естественном языке
AI-агент понимает команды простым текстом и выполняет их в Kaiten:

| Команда | Что делает |
| :--- | :--- |
| «Покажи задачи Маши» | Список задач ответственного |
| «Покажи просроченные» | Все просроченные задачи |
| «Что в Ревью?» | Задачи в колонке |
| «Закрой задачу "Дизайн-система"» | Перемещение в Готово |
| «Перенеси "API" в работу» | Смена колонки |
| «Добавь задачу "Помыть кота" на Сашу» | Создание задачи |
| «Перенеси срок "Отчёт" на 10 октября» | Изменение дедлайна |
| «Добавь Ивана в задачу "ТЗ"» | Добавление участника |

**Под капотом:** GPT-4o-mini через Timeweb AI парсит команду в JSON, сервер выполняет действие через Kaiten API.

## 🛠 Стек технологий

**Backend:**
- Python 3.12
- FastAPI + Uvicorn
- SQLite (кэш, rate limits)
- Kaiten REST API
- Timeweb AI (GPT-4o-mini)

**Frontend:**
- Чистый HTML/CSS/JS (без фреймворков)
- Chart.js для графиков
- Адаптивный дизайн, анимации

**Инфраструктура:**
- Nginx (reverse proxy)
- systemd (автозапуск сервисов)
- Cron (ежедневный сброс демо-данных в 3:00)
- Let's Encrypt (SSL)
